## Projetos

### **Evolvy** — Plataforma de Evolução Pessoal

Começou como projeto acadêmico, virou MVP real. Sistema completo de acompanhamento em dieta, treino e bem-estar. Você coloca seus dados, a IA (Gemini) gera planos personalizados, você acompanha progresso em tempo real.

**Stack:** React • TypeScript • Vite • Tailwind CSS • Supabase • Gemini API

**O que aprendi:** Autenticação de verdade, integração com IA, state management em apps complexos.

→ [Ver repositório](https://github.com/GusAraujodev/Evolvy)

---

### **Livraria Gilede Vieira** — E-commerce Profissional

Projeto integrador (trabalho acadêmico + real). E-commerce completo de livraria com backend robusto e frontend responsivo. Integra com Mercado Pago, tem autenticação, painel administrativo, tudo funcionando.

**Backend:** Java • Spring Boot • PostgreSQL • Spring Security • JWT  
**Frontend:** React • TypeScript • Tailwind CSS

**O que aprendi:** Arquitetura real (controllers, services, repositories, DTOs), autenticação JWT, integração com API de pagamento, relacionamentos complexos no banco.

→ Backend: [Ver](https://github.com/GusAraujodev/Projeto-Integrador-Gilede-Vieira--BackEnd)  
→ Frontend: [Ver](https://github.com/GusAraujodev/Projeto-Integrador-Gilede-Vieira--FrontEnd)
